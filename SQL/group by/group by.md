# SQL — GROUP BY Cheat Sheet

## 1. Группировка строк

`GROUP BY` объединяет строки с одинаковыми значениями в группы.

```sql
SELECT home_type
FROM Rooms
GROUP BY home_type;
```

Результат — по одной строке на каждый уникальный тип жилья.

## 2. Группировка с агрегатными функциями

Для каждой группы можно вычислять показатели, например среднюю цену:

```sql
SELECT home_type, AVG(price) AS avg_price
FROM Rooms
GROUP BY home_type;
```

`AVG(price)` вычисляет среднюю цену для каждого типа жилья.

## 3. Что можно указывать в `SELECT`?

При использовании `GROUP BY` выбирай:

- **Поля группировки** — например, `home_type`.
- **Агрегатные функции** — например, `AVG(price)`.
- **Литералы** — фиксированные значения, например `'literal'`.

Обычное поле, которое не входит в группировку и не используется в агрегатной функции, выбирать не следует.

## 4. Группировка по нескольким столбцам

```sql
SELECT home_type, has_tv, AVG(price) AS avg_price
FROM Rooms
GROUP BY home_type, has_tv;
```

Сначала строки объединяются по комбинации `home_type` и `has_tv`. Каждая уникальная комбинация образует отдельную группу.

## 5. Важные правила

- `NULL` при группировке считается одинаковым значением, поэтому все `NULL` попадают в одну группу.
- `GROUP BY` сам по себе не вычисляет сумму или среднее — для этого нужны агрегатные функции.
- `AS` задаёт псевдоним столбца результата.

## Кратко

| Конструкция | Назначение |
|---|---|
| `GROUP BY column` | Группировка по столбцу |
| `GROUP BY col1, col2` | Группировка по комбинации столбцов |
| `AVG(column)` | Среднее значение |
| `COUNT(*)` | Количество строк |
| `SUM(column)` | Сумма значений |
| `MIN(column)` | Минимум |
| `MAX(column)` | Максимум |

**Запомни:** `GROUP BY` формирует группы, а агрегатные функции вычисляют показатели для каждой группы.
