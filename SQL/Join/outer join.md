# SQL — Внешнее соединение OUTER JOIN

## 1. Что такое OUTER JOIN

**Внешнее соединение** возвращает все строки одной или обеих таблиц, включая строки без совпадений. Если пары нет, поля другой таблицы заполняются `NULL`.

`OUTER` можно опустить: `LEFT JOIN` = `LEFT OUTER JOIN`.

Просто `JOIN` без уточнения — это `INNER JOIN`.

## 2. Виды соединений

| Вид | Что возвращает |
|---|---|
| `INNER JOIN` | Только строки с совпадениями в обеих таблицах |
| `LEFT JOIN` | Все строки левой таблицы + совпадения из правой |
| `RIGHT JOIN` | Все строки правой таблицы + совпадения из левой |
| `FULL OUTER JOIN` | Все строки обеих таблиц, с совпадениями и без |

## 3. LEFT JOIN — левое соединение

Все строки левой таблицы сохраняются. Если совпадения справа нет, столбцы правой таблицы становятся `NULL`.

```sql
SELECT Timepair.id, start_pair, end_pair,
       Schedule.id, date, class
FROM Timepair
LEFT JOIN Schedule
    ON Schedule.number_pair = Timepair.id;
```

**Важно:** количество строк может быть больше количества строк левой таблицы. Если одной строке слева соответствуют несколько строк справа, каждая пара попадёт в результат отдельно.

## 4. Найти строки без пары — ANTI JOIN

Чтобы найти записи левой таблицы, для которых нет совпадений в правой, используют `LEFT JOIN` вместе с `IS NULL`.

```sql
SELECT Timepair.id, start_pair, end_pair
FROM Timepair
LEFT JOIN Schedule
    ON Schedule.number_pair = Timepair.id
WHERE Schedule.number_pair IS NULL;
```

Результат — звонки, на которые не назначено ни одного занятия.

- `LEFT JOIN` сохраняет все строки слева.
- `WHERE Schedule.number_pair IS NULL` оставляет только строки без совпадения справа.

Такой приём называют **анти-соединением (ANTI JOIN)**. В MySQL для него нет отдельного оператора.

## 5. RIGHT JOIN — правое соединение

Все строки правой таблицы сохраняются. Если совпадения слева нет, поля левой таблицы заполняются `NULL`.

```sql
SELECT Timepair.id, start_pair, end_pair,
       Schedule.id, date, class
FROM Timepair
RIGHT JOIN Schedule
    ON Schedule.number_pair = Timepair.id;
```

Результат зависит от данных: если каждая строка справа имеет пару слева, `RIGHT JOIN` может вернуть тот же набор строк, что и `INNER JOIN`.

## 6. FULL OUTER JOIN — полное соединение

Возвращает:
1. Все совпавшие строки.
2. Строки левой таблицы без пары.
3. Строки правой таблицы без пары.

**MySQL не поддерживает `FULL OUTER JOIN` напрямую.** Его можно имитировать с помощью `LEFT JOIN`, `RIGHT JOIN`, `UNION ALL` и фильтра `IS NULL`.

```sql
SELECT l.id AS left_id, r.id AS right_id
FROM LeftTable AS l
LEFT JOIN RightTable AS r
    ON l.id = r.id

UNION ALL

SELECT l.id AS left_id, r.id AS right_id
FROM LeftTable AS l
RIGHT JOIN RightTable AS r
    ON l.id = r.id
WHERE l.id IS NULL;
```

- Первая часть возвращает все строки левой таблицы и совпадения.
- Вторая добавляет только строки правой таблицы без пары.
- В обеих частях `SELECT` должно быть одинаковое количество столбцов в одинаковом порядке.
- `UNION ALL` сохраняет все строки, не удаляя дубликаты.

Для фильтрации непарных строк выбирайте столбец левой таблицы, который гарантированно `NULL` только при отсутствии совпадения, например её первичный ключ.

## 7. Как выбрать соединение

| Задача | Используйте |
|---|---|
| Только совпавшие записи | `INNER JOIN` |
| Все записи левой таблицы | `LEFT JOIN` |
| Все записи правой таблицы | `RIGHT JOIN` |
| Все записи обеих таблиц | `FULL OUTER JOIN` |
| Только записи слева без пары | `LEFT JOIN ... WHERE right.key IS NULL` |
| Только записи справа без пары | `RIGHT JOIN ... WHERE left.key IS NULL` |

**Главное правило:** `LEFT JOIN` гарантирует наличие всех строк левой таблицы, но не гарантирует, что итоговых строк будет столько же. Несколько совпадений для одной строки создают несколько строк результата.
