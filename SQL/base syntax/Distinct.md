# SQL — DISTINCT Cheat Sheet

## 1. Удаление дубликатов

`DISTINCT` — возвращает только уникальные строки.

```sql
SELECT DISTINCT class
FROM Student_in_class;
```

## 2. Несколько столбцов

Уникальность проверяется по **комбинации всех указанных столбцов**.

```sql
SELECT DISTINCT first_name, last_name
FROM User;
```

Одинаковые пары имён и фамилий выводятся только один раз.

## ⚡ Запомнить

- `DISTINCT` ставится сразу после `SELECT`.
- Без `DISTINCT` дубликаты сохраняются.
- Для нескольких столбцов сравнивается вся комбинация значений.
- `DISTINCT` не удаляет данные из таблицы — он убирает дубликаты только из результата запроса.

### Шаблон

```sql
SELECT DISTINCT столбец1, столбец2
FROM название_таблицы;
```
