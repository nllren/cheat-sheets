# 📘 SQL — Встроенные функции

**Функция** — выполняет операцию над данными и возвращает результат.

## 1. Основные функции

| Функция | Назначение | Пример | Результат |
|---|---|---|---|
| `UPPER()` | В верхний регистр | `UPPER('sql')` | `SQL` |
| `LOWER()` | В нижний регистр | `LOWER('SQL')` | `sql` |
| `LENGTH()` | Длина строки в байтах | `LENGTH('hello')` | `5` |
| `YEAR()` | Получить год | `YEAR('2022-06-16')` | `2022` |
| `INSTR()` | Позиция подстроки | `INSTR('sql-academy', 'academy')` | `5` |
| `LEFT()` | Первые N символов | `LEFT('SQL', 2)` | `SQ` |
| `NOW()` | Текущие дата и время | `NOW()` | Текущие дата и время |

## 2. Функции для столбцов

Функция применяется к каждой строке таблицы.

```sql
SELECT
    member_name,
    LENGTH(member_name) AS name_length
FROM FamilyMembers;
```

## 3. Комбинирование функций

Результат одной функции можно передать в другую.

```sql
SELECT UPPER(LEFT('sql-academy', 3)) AS str;
```

Результат: `SQL`

## 4. Расчёты с функциями

Длина фамилии, если имя и фамилия разделены одним пробелом:

```sql
SELECT
    member_name,
    LENGTH(member_name) - INSTR(member_name, ' ') AS lastname_length
FROM FamilyMembers;
```

`LENGTH()` — длина всей строки, `INSTR()` — позиция пробела.

---

### ⚡ Запомни

- Функции могут принимать **0, 1 или несколько аргументов**.
- `AS` задаёт имя результирующему столбцу.
- Функции можно вкладывать друг в друга.
- Результаты функций можно использовать в арифметических выражениях.
- В MySQL `LENGTH()` считает **байты**, а не символы. Для количества символов используй `CHAR_LENGTH()`.
