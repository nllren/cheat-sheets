# 📘 SQL — Литералы

**Литерал** — фиксированное значение, указанное явно.

## 1. Типы литералов

| Тип | Пример |
|---|---|
| Строковый | `'SQL'` |
| Числовой | `12`, `2.9`, `-10` |
| Логический | `TRUE`, `FALSE` |
| Отсутствие значения | `NULL` |
| Дата и время | `'2020-01-01'` |

## 2. Строки

```sql
SELECT 'Hello world';
SELECT 'Hello\nWorld';
```

- Строки заключаются в кавычки `'...'`.
- `\n` — перевод строки в MySQL.
- Двойные кавычки тоже могут обозначать строки в MySQL.

## 3. Числа и операторы

| Оператор | Значение | Пример |
|:---:|---|---|
| `+` | Сложение | `2 + 3 = 5` |
| `-` | Вычитание | `5 - 2 = 3` |
| `*` | Умножение | `3 * 4 = 12` |
| `/` | Деление | `5 / 2 = 2.5` |
| `DIV` | Целочисленное деление | `10 DIV 4 = 2` |
| `%` или `MOD` | Остаток от деления | `11 % 5 = 1` |

Дробные числа записываются через точку: `2.5`.

```sql
SELECT (5 * 2 - 6) / 2 AS Result;
```

## 4. Дата и время

| Тип | Формат | Пример |
|---|---|---|
| Дата | `YYYY-MM-DD` | `'2020-01-01'` |
| Время | `HH:MM:SS` | `'12:30:00'` |
| Дата + время | `YYYY-MM-DD HH:MM:SS` | `'2020-01-01 12:30:00'` |

```sql
SELECT *
FROM FamilyMembers
WHERE birthday > '1970-12-30';
```

## 5. Логические значения

```sql
SELECT TRUE, FALSE;
```

В MySQL:
- `TRUE` = `1`
- `FALSE` = `0`

## 6. NULL

`NULL` — отсутствие значения (не то же самое, что `0` или пустая строка `''`).

Для проверки используй:

```sql
IS NULL
IS NOT NULL
```

**Запомни:** `NULL = NULL` не возвращает `TRUE`.
