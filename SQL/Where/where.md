# SQL — WHERE Cheat Sheet

## 1. Фильтрация строк

`WHERE` — выбирает строки, удовлетворяющие условию.

```sql
SELECT [DISTINCT] столбцы
FROM таблица
WHERE условие;
```

## 2. Операторы сравнения

| Оператор | Значение |
|---|---|
| `=` | Равно |
| `<>`, `!=` | Не равно |
| `>` | Больше |
| `<` | Меньше |
| `>=` | Больше или равно |
| `<=` | Меньше или равно |
| `<=>` | Сравнение с учётом `NULL` (MySQL) |

```sql
SELECT *
FROM Student
WHERE YEAR(birthday) > 2000;
```

## 3. Логические операторы

| Оператор | Значение |
|---|---|
| `AND` | Оба условия истинны |
| `OR` | Хотя бы одно истинно |
| `NOT` | Отрицание условия |
| `XOR` | Истинно только одно из двух условий |

```sql
-- Оба условия
WHERE plane = 'Boeing' AND town_from = 'London'

-- Хотя бы одно условие
WHERE town_to = 'Paris' OR plane = 'Airbus'

-- Исключить условие
WHERE NOT town_to = 'Moscow'

-- Только одно условие
WHERE town_from = 'Moscow' XOR town_to = 'Paris'
```

## 4. Приоритет операторов

От высшего к низшему:

1. `NOT`
2. `AND`
3. `XOR`
4. `OR`

Используй скобки `()` для изменения порядка вычислений и повышения читаемости.

```sql
SELECT *
FROM Trip
WHERE town_from = 'Paris'
   OR (plane = 'Boeing' AND town_to <> 'Moscow');
```

## 5. Работа с NULL

```sql
WHERE column_name IS NULL
WHERE column_name IS NOT NULL
```

- `NULL` означает отсутствие значения.
- `= NULL` использовать нельзя для проверки отсутствия значения.
- `NULL = NULL` возвращает `NULL`.
- `NULL <=> NULL` возвращает `1` в MySQL.

## ⚡ Запомни

- `WHERE` фильтрует строки до вывода результата.
- `AND` сужает выборку, `OR` расширяет.
- `NOT` инвертирует условие.
- Скобки помогают явно задать логику запроса.
- Строковые значения заключаются в кавычки: `'London'`.
