# SQL — LIKE Cheat Sheet

## 1. `LIKE` — поиск по шаблону

```sql
SELECT name, email
FROM Users
WHERE email LIKE '%@hotmail.%';
```

`LIKE` проверяет, соответствует ли строка заданному шаблону. `NOT LIKE` выбирает строки, которые **не соответствуют** шаблону.

## 2. Специальные символы

| Символ | Значение | Пример |
|---|---|---|
| `%` | Любая последовательность символов, включая 0 символов | `'text%'` |
| `_` | Ровно один любой символ | `'_ext'` |

## 3. Примеры шаблонов

| Шаблон | Что ищет | Примеры совпадений |
|---|---|---|
| `'text%'` | Начинается с `text` | `text`, `text123` |
| `'%text'` | Заканчивается на `text` | `text`, `mytext` |
| `'%text%'` | Содержит `text` | `text`, `mytext123` |
| `'_ext'` | 4 символа, последние — `ext` | `text`, `next` |
| `'begin%end'` | Начинается с `begin`, заканчивается на `end` | `beginend`, `begin123end` |
| `'%@hotmail.%'` | Содержит `@hotmail.` | `user@hotmail.com` |

## 4. Экранирование `%` и `_`

Чтобы искать `%` или `_` как обычные символы, а не как шаблоны, их нужно экранировать.

По умолчанию используется обратный слеш `\`:

```sql
SELECT job_id
FROM Jobs
WHERE progress LIKE '3\%';
```

Альтернативный символ экранирования можно задать через `ESCAPE`:

```sql
SELECT job_id
FROM Jobs
WHERE progress LIKE '3!%' ESCAPE '!';
```

Здесь `!%` означает буквальный символ `%`.

## 5. Кратко

- `LIKE` — поиск по шаблону.
- `NOT LIKE` — исключение совпадений.
- `%` — любое количество символов.
- `_` — ровно один символ.
- `ESCAPE` — задаёт символ экранирования.
- В MySQL поиск через `LIKE` по умолчанию обычно нечувствителен к регистру, но это зависит от используемой сортировки (collation).
