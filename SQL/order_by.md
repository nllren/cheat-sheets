# SQL — ORDER BY Cheat Sheet

## 1. Сортировка результатов

`ORDER BY` сортирует строки результата запроса. Без него порядок строк не гарантирован.

```sql
SELECT столбцы
FROM таблица
WHERE условие
ORDER BY столбец [ASC | DESC];
```

- `ASC` — по возрастанию (по умолчанию).
- `DESC` — по убыванию.

```sql
-- По алфавиту
SELECT name FROM Company
ORDER BY name ASC;

-- От дорогих к дешёвым
SELECT * FROM Products
ORDER BY price DESC;
```

## 2. Как сортируются данные

| Тип данных | `ASC` | `DESC` |
|---|---|---|
| Строки | По алфавиту | В обратном порядке |
| Числа | От меньшего к большему | От большего к меньшему |
| Даты | От ранних к поздним | От поздних к ранним |
| Boolean | `FALSE` → `TRUE` | `TRUE` → `FALSE` |
| `NULL` в MySQL | Обычно в начале | Обычно в конце |

Порядок строк зависит от правил сортировки (collation), особенно для текста.

## 3. Сортировка по нескольким столбцам

```sql
SELECT DISTINCT town_from, town_to
FROM Trip
ORDER BY town_from ASC, town_to DESC;
```

Сначала сортировка по `town_from` по возрастанию. Если значения совпадают — по `town_to` по убыванию.

**Важно:** направление сортировки применяется только к столбцу, после которого указано.

```sql
ORDER BY town_from, town_to DESC
```

Не то же самое, что:

```sql
ORDER BY town_from DESC, town_to DESC
```

Если направление не указано, используется `ASC`.

## 4. Полезные правила

- `WHERE` фильтрует строки **до сортировки**.
- `ORDER BY` задаёт порядок строк в результате.
- Можно сортировать по нескольким столбцам — через запятую.
- Для одинаковых значений порядок между строками не гарантирован, если не добавить дополнительный столбец сортировки.

## Шаблон

```sql
SELECT столбцы
FROM таблица
WHERE условие
ORDER BY столбец_1 ASC, столбец_2 DESC;
```
