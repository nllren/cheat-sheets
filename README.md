## 📌 Описание

Персональный репозиторий со структурированными шпаргалками, конспектами и быстрыми подсказками по программированию, базам данных и инструментам разработки.

Материалы отсортированы по технологиям и темам. Для каждого раздела создана отдельная папка с детальными файлами в формате `Markdown` с примерами кода и подсвеченным синтаксисом.
