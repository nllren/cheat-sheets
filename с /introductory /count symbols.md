# Шпаргалка: подсчёт символов в C

## 1. Подсчёт символов с помощью `while`

Программа читает входной поток посимвольно и считает количество символов до конца ввода.

```c
#include <stdio.h>

int main(void)
{
    long nc = 0;

    while (getchar() != EOF)
        ++nc;

    printf("%ld\n", nc);

    return 0;
}
```

Как работает программа:

1. `nc = 0` — счётчик начинается с нуля.
2. `getchar()` читает очередной символ.
3. Если результат не равен `EOF`, выполняется `++nc`.
4. Когда ввод заканчивается, цикл завершается.
5. `printf()` выводит количество прочитанных символов.

## 2. Операторы `++` и `--`

- `++nc` — увеличить `nc` на единицу.
- `--nc` — уменьшить `nc` на единицу.

Например:

```c
nc = nc + 1;
```

можно записать короче:

```c
++nc;
```

Есть две формы инкремента:

| Форма | Название | Что делает |
|---|---|---|
| `++nc` | Префиксная | Увеличивает переменную на 1 |
| `nc++` | Постфиксная | Увеличивает переменную на 1 |

Если оператор используется отдельно, как `++nc;` или `nc++;`, итоговое значение переменной одинаковое. Разница возникает, когда результат инкремента используется внутри другого выражения.

## 3. Почему используется тип `long`?

Счётчик символов может стать очень большим. Тип `long` позволяет хранить большие целые значения, чем некоторые реализации `int`.

```c
long nc = 0;
```

Для вывода переменной типа `long` используется спецификатор `%ld`:

```c
printf("%ld\n", nc);
```

Спецификаторы формата должны соответствовать типам аргументов.

## 4. Подсчёт символов с помощью `for`

Ту же задачу можно решить циклом `for`:

```c
#include <stdio.h>

int main(void)
{
    double nc;

    for (nc = 0; getchar() != EOF; ++nc)
        ;

    printf("%.0f\n", nc);

    return 0;
}
```

В этой версии:

- `nc = 0` — инициализация счётчика;
- `getchar() != EOF` — условие продолжения;
- `++nc` — увеличение счётчика после каждой итерации;
- `;` — пустой оператор, выполняющий роль тела цикла.

Тип `double` позволяет хранить большие целые значения с ограничениями точности, но для счётчика целых символов обычно логичнее использовать целочисленный тип, например `long`.

Формат `%.0f` выводит вещественное число без десятичных знаков.

## 5. Что происходит при пустом вводе?

Если поток пуст, первый вызов `getchar()` возвращает `EOF`. Условие цикла сразу становится ложным, поэтому тело не выполняется, а счётчик остаётся равным нулю.

Это важное свойство циклов `while` и `for`: **условие проверяется до выполнения тела**.

## Главное запомнить

- `getchar() != EOF` позволяет читать поток до конца.
- `++nc` увеличивает счётчик на единицу.
- `long` подходит для целочисленного счётчика; `%ld` используется для его вывода.
- Циклы `while` и `for` позволяют реализовать один и тот же алгоритм.
- Пустой ввод должен обрабатываться корректно и давать результат `0`.
