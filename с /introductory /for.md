# Шпаргалка: цикл `for` в языке C

## 1. Пример программы преобразования температур

```c
#include <stdio.h>

/* Таблица температур по Фаренгейту и Цельсию */
int main(void)
{
    int fahr;

    for (fahr = 0; fahr <= 300; fahr = fahr + 20)
        printf("%3d %6.1f\n", fahr,
               (5.0 / 9.0) * (fahr - 32));

    return 0;
}
```

Программа выводит температуру по Фаренгейту и соответствующую температуру по Цельсию.

Формула преобразования:

\[
C = \frac{5}{9}(F - 32)
\]

## 2. Как работает `for`

Общий синтаксис:

```c
for (инициализация; условие; изменение)
    оператор;
```

Три части заголовка разделяются **точками с запятой**.

| Часть | Пример | Назначение |
|---|---|---|
| Инициализация | `fahr = 0` | Выполняется один раз перед циклом |
| Условие | `fahr <= 300` | Определяет, продолжать ли цикл |
| Изменение | `fahr = fahr + 20` | Выполняется после каждой итерации |

Порядок выполнения:

1. Инициализация.
2. Проверка условия.
3. Выполнение тела цикла, если условие истинно.
4. Изменение переменной.
5. Возврат к проверке условия.

Когда условие становится ложным, цикл завершается.

## 3. Выражения прямо внутри функций

Не обязательно сначала сохранять вычисление в отдельную переменную:

```c
double celsius;
celsius = (5.0 / 9.0) * (fahr - 32);
printf("%6.1f\n", celsius);
```

Можно вычислить значение непосредственно при вызове функции:

```c
printf("%6.1f\n", (5.0 / 9.0) * (fahr - 32));
```

Это позволяет обходиться меньшим количеством переменных.

## 4. `for` и `while`

Эти циклы во многих случаях взаимозаменяемы.

Вариант с `for`:

```c
for (fahr = 0; fahr <= 300; fahr += 20)
    printf("%d\n", fahr);
```

Эквивалентный вариант с `while`:

```c
fahr = 0;

while (fahr <= 300) {
    printf("%d\n", fahr);
    fahr += 20;
}
```

**Когда удобнее `for`:** когда начальное значение, условие и изменение переменной удобно записать в одном месте.

**Когда удобнее `while`:** когда логика продолжения цикла сложнее или изменение переменной происходит в разных местах.

## 5. Формат вывода `printf`

- `%d` — целое число.
- `%f` — вещественное число.
- `%6.1f` — вещественное число в поле шириной 6 символов с одним знаком после десятичной точки.
- `%3d` — целое число в поле шириной 3 символа.
- `\n` — переход на новую строку.

Важно: `5.0 / 9.0` выполняет вещественное деление. Если написать `5 / 9`, результатом целочисленного деления в C будет `0`.

## 6. Упражнение: вывести температуры в обратном порядке

Чтобы выводить значения от 300 до 0 с шагом 20, нужно изменить начальное значение, условие и шаг:

```c
#include <stdio.h>

int main(void)
{
    int fahr;

    for (fahr = 300; fahr >= 0; fahr -= 20)
        printf("%3d %6.1f\n", fahr,
               (5.0 / 9.0) * (fahr - 32));

    return 0;
}
```

Здесь:
- `fahr = 300` — начинаем с 300;
- `fahr >= 0` — продолжаем, пока значение не станет меньше нуля;
- `fahr -= 20` — уменьшаем значение на 20 после каждой итерации.

## Главное запомнить

- `for` объединяет инициализацию, условие и изменение переменной.
- Выражения можно вычислять непосредственно внутри вызова функции.
- `for` и `while` часто позволяют реализовать один и тот же алгоритм.
- Для обратного перебора нужно изменить начальное значение, условие и направление шага.
- Для точных вычислений с дробями используйте вещественные константы, например `5.0` и `9.0`.
