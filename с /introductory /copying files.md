# Шпаргалка: копирование файлов в C

## 1. Идея программы

Копирование потока — это чтение входных данных по одному символу и вывод каждого прочитанного символа, пока не встретится конец потока.

Алгоритм:

1. Прочитать символ с помощью `getchar()`.
2. Проверить, не равен ли он `EOF`.
3. Если это не конец потока — вывести символ с помощью `putchar()`.
4. Повторять, пока не достигнут конец потока.

## 2. Основной вариант программы

```c
#include <stdio.h>

/* Копирование входного потока в выходной */
int main(void)
{
    int c;

    c = getchar();

    while (c != EOF) {
        putchar(c);
        c = getchar();
    }

    return 0;
}
```

Оператор `!=` означает **«не равно»**.

## 3. Короткий вариант с `while`

В C присваивание само является выражением и имеет значение — то, которое было присвоено переменной.

Поэтому чтение можно объединить с проверкой условия:

```c
#include <stdio.h>

int main(void)
{
    int c;

    while ((c = getchar()) != EOF)
        putchar(c);

    return 0;
}
```

Как работает условие:

- `getchar()` считывает очередной символ;
- `c = getchar()` сохраняет результат в `c`;
- `!= EOF` проверяет, не завершился ли ввод;
- если символ прочитан успешно, выполняется `putchar(c)`.

**Важно:** двойные скобки необходимы.

```c
while ((c = getchar()) != EOF)
```

Без скобок выражение:

```c
c = getchar() != EOF
```

будет означать другое: сначала сравнить результат `getchar()` с `EOF`, а затем записать в `c` число `0` или `1`.

## 4. Почему переменная имеет тип `int`, а не `char`?

Функция `getchar()` возвращает:

- значение прочитанного символа;
- специальное значение `EOF`, если достигнут конец потока или произошла ошибка чтения.

Тип `char` не подходит для надёжного хранения обоих вариантов результата. Поэтому для переменной обычно используют `int`.

`EOF` — символическая константа, объявленная в заголовочном файле `<stdio.h>`. Её конкретное числовое значение не нужно запоминать.

## 5. Операторы и функции

| Запись | Значение |
|---|---|
| `getchar()` | Прочитать один символ |
| `putchar(c)` | Вывести символ |
| `c != EOF` | Проверить, что это не конец потока |
| `c = getchar()` | Прочитать символ и сохранить его |
| `while (условие)` | Повторять, пока условие истинно |


## Главное запомнить

- `getchar()` читает один символ, `putchar()` выводит один символ.
- `EOF` обозначает конец входного потока или ошибку чтения.
- Для результата `getchar()` используют `int`.
- Конструкция `while ((c = getchar()) != EOF)` — стандартный компактный способ читать поток до конца.
- Скобки вокруг присваивания в условии нужны из-за приоритета операторов.
