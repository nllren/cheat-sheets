# C — Переменные и арифметические выражения

## 1. Объявление переменных

В C переменные нужно объявлять до использования. При объявлении указывают тип и имя.

```c
int age;
float temperature;

int lower, upper, step;
```

Основные типы:

| Тип | Назначение |
|---|---|
| `int` | Целые числа |
| `float` | Вещественные числа |
| `double` | Вещественные числа повышенной точности |
| `char` | Символ |

## 2. Присваивание и арифметика

Оператор `=` присваивает переменной значение.

```c
int a = 10;
int b = 3;

int sum = a + b;         // 13
int difference = a - b; // 7
int product = a * b;    // 30
int division = a / b;   // 3
int remainder = a % b;  // 1
```

**Важно:** при делении двух целых чисел дробная часть отбрасывается.

```c
printf("%d\n", 5 / 9);      // 0
printf("%f\n", 5.0 / 9.0);  // 0.555556
```

Чтобы получить вещественный результат, используйте вещественные числа, например `5.0` и `9.0`.

## 4. Цикл while

`while` повторяет выполнение тела цикла, пока условие истинно.

```c
int i = 0;

while (i <= 3) {
    printf("%d\n", i);
    i = i + 1;
}
```

Результат:

```text
0
1
2
3
```

- Условие записывается в круглых скобках.
- Тело цикла обычно заключается в `{ }`.
- Важно изменять переменные, от которых зависит условие, иначе цикл может стать бесконечным.

## 5. Пример: перевод Фаренгейта в Цельсий

Формула:

\[
C = \frac{5}{9}(F - 32)
\]

где `F` — температура по Фаренгейту, `C` — по Цельсию.

### Целочисленный вариант

```c
#include <stdio.h>

int main(void) {
    int fahr, celsius;
    int lower = 0, upper = 300, step = 20;

    fahr = lower;

    while (fahr <= upper) {
        celsius = 5 * (fahr - 32) / 9;
        printf("%3d %6d\n", fahr, celsius);
        fahr = fahr + step;
    }

    return 0;
}
```

Из-за целочисленного деления результат округляется отбрасыванием дробной части в промежуточных вычислениях.

### Вариант с вещественными числами

```c
#include <stdio.h>

int main(void) {
    float fahr, celsius;
    int lower = 0, upper = 300, step = 20;

    fahr = lower;

    while (fahr <= upper) {
        celsius = (5.0 / 9.0) * (fahr - 32.0);
        printf("%3.0f %6.1f\n", fahr, celsius);
        fahr = fahr + step;
    }

    return 0;
}
```

`5.0 / 9.0` выполняет вещественное деление, поэтому вычисление получается точнее.

## 6. Форматированный вывод printf

Форматная строка задаёт, как выводить значения.

| Формат | Значение |
|---|---|
| `%d` | Целое число |
| `%6d` | Целое число в поле шириной минимум 6 символов |
| `%f` | Вещественное число |
| `%6f` | Вещественное число в поле шириной минимум 6 символов |
| `%.2f` | Две цифры после десятичной точки |
| `%6.2f` | Ширина минимум 6 символов, две цифры после точки |
| `%c` | Символ |
| `%s` | Строка |
| `%x` | Шестнадцатеричное представление целого числа |
| `%o` | Восьмеричное представление целого числа |
| `%%` | Символ `%` |

Пример:

```c
int age = 25;
float height = 1.75;

printf("Возраст: %d\n", age);
printf("Рост: %.2f\n", height);
printf("%6d %6.2f\n", age, height);
```

В записи `%6.2f`:
- `6` — минимальная ширина поля;
- `.2` — количество цифр после точки;
- `f` — формат вещественного числа.

Ширина — это минимум, а не ограничение: если значение длиннее, поле расширяется. Числа по умолчанию выравниваются по правому краю.

**Важно:** спецификаторы формата должны соответствовать типам аргументов и их количеству.

## Главное запомнить

- В C переменную объявляют до использования: `int x;`.
- `int` хранит целые числа, `float` и `double` — вещественные.
- Деление `int / int` отбрасывает дробную часть.
- `while` повторяет код, пока условие истинно.
- `printf()` выводит значения по форматной строке: `%d` для целых, `%f` для вещественных.
- `\n` переводит вывод на новую строку, `\t` добавляет табуляцию.
- Формат `%6.2f` задаёт минимальную ширину 6 символов и 2 знака после точки.
