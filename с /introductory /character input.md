# Шпаргалка: символьный ввод-вывод в C

## 1. Потоки символов

В языке C текстовый ввод-вывод рассматривается как работа с **потоками символов**.

- Поток — это последовательность символов.
- Текст обычно организован в строки.
- Каждая строка заканчивается символом новой строки `\n`.
- Строка может быть пустой или содержать любое количество символов.

Стандартная библиотека C организует работу с потоками, поэтому программисту не нужно самостоятельно управлять их физическим представлением.

## 2. Функция `getchar()`

Читает один символ из стандартного потока ввода и возвращает его.

```c
int c;

c = getchar();
```

Обычно символ вводится с клавиатуры.

Пример чтения одного символа:

```c
#include <stdio.h>

int main(void)
{
    int c;

    c = getchar();
    printf("Вы ввели: ");
    putchar(c);
    putchar('\n');

    return 0;
}
```

**Почему используется `int`, а не `char`?**

`getchar()` возвращает `int`, чтобы можно было представить любой символ типа `unsigned char`, а также специальное значение `EOF`, обозначающее конец ввода или ошибку чтения.

## 3. Функция `putchar()`

Выводит один символ в стандартный поток вывода.

```c
putchar(c);
```

Например:

```c
putchar('A');
putchar('\n');
```

Результат:

```text
A
```

`putchar()` принимает целочисленное значение, соответствующее выводимому символу.

## 4. Сравнение функций

| Функция | Назначение | Пример |
|---|---|---|
| `getchar()` | Считывает один символ | `c = getchar();` |
| `putchar()` | Выводит один символ | `putchar(c);` |
| `printf()` | Выводит форматированный текст | `printf("%d", n);` |

Вызовы `putchar()` и `printf()` можно чередовать. Вывод появится в порядке выполнения вызовов.

## 5. Чтение и вывод нескольких символов

```c
#include <stdio.h>

int main(void)
{
    int c;

    while ((c = getchar()) != EOF)
        putchar(c);

    return 0;
}
```

Эта программа копирует символы ввода в вывод, пока не встретит `EOF` — конец потока или ошибку чтения.

## Главное запомнить

- `getchar()` — получить один символ.
- `putchar()` — вывести один символ.
- `printf()` — вывести форматированный текст.
- Для хранения результата `getchar()` обычно используют `int`, чтобы корректно проверять `EOF`.
- Символ `\n` обозначает переход на новую строку.
