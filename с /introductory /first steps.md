# C — Первые шаги

## 1. Первая программа: Hello, World!

Программа выводит текст `hello, world` на экран.

```c
#include <stdio.h>

int main(void)
{
    printf("hello, world\n");
    return 0;
}
```

## 2. Из чего состоит программа

- `#include <stdio.h>` — подключает стандартную библиотеку ввода-вывода, в которой объявлена функция `printf`.
- `main()` — главная функция, с которой начинается выполнение программы.
- `{ }` — фигурные скобки обозначают начало и конец тела функции.
- `printf()` — функция для вывода текста.
- `return 0;` — сообщает об успешном завершении программы.
- `;` — завершает оператор.

## 3. Вывод текста с помощью `printf()`

```c
printf("Hello, World!\n");
```

Текст в двойных кавычках называется **строкой** или строковой константой.

`printf()` не добавляет переход на новую строку автоматически. Для этого используют `\n`.

```c
printf("Hello, ");
printf("World!");
printf("\n");
```

Результат будет таким же:

```text
Hello, World!
```

## 4. Управляющие последовательности

Специальные комбинации символов позволяют выводить символы управления.

| Последовательность | Значение |
|---|---|
| `\n` | Переход на новую строку |
| `\t` | Табуляция |
| `\b` | Возврат на один символ назад |
| `\"` | Двойная кавычка внутри строки |
| `\\` | Обратная косая черта `\` |

Пример:

```c
printf("Имя:\tИван\n");
printf("\"Привет!\"\n");
```

Результат:

```text
Имя:    Иван
"Привет!"
```

Нельзя просто перенести текст внутри обычной строковой константы на новую строку исходного кода. Для перехода строки в выводе используйте `\n`.

## 5. Компиляция и запуск

В отличие от интерпретируемых языков, исходный код C обычно сначала компилируют в исполняемую программу.

Например, если установлен компилятор GCC:

```bash
gcc hello.c -o hello
```

Запуск в Unix/Linux:

```bash
./hello
```

Этапы работы:

1. Написать код и сохранить его в файле `.c`.
2. Скомпилировать исходный код.
3. Исправить ошибки компиляции, если они есть.
4. Запустить исполняемый файл и посмотреть результат.

## Главное запомнить

- Выполнение программы начинается с `main()`.
- `printf()` выводит текст, но сам по себе не переходит на новую строку.
- `\n` добавляет переход на новую строку.
- Строки заключаются в двойные кавычки.
- В C операторы обычно заканчиваются точкой с запятой `;`.
- Компиляция преобразует исходный код в исполняемую программу.
