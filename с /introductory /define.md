# Шпаргалка: символические константы `#define` в C

## 1. Зачем нужен `#define`

Числовые константы вроде `300` и `20` не объясняют, что они означают. Чтобы код было легче читать и изменять, им дают понятные имена.

```c
#define LOWER 0
#define UPPER 300
#define STEP 20
```

- `LOWER` — нижняя граница диапазона.
- `UPPER` — верхняя граница диапазона.
- `STEP` — шаг изменения температуры.

## 2. Пример программы

```c
#include <stdio.h>

#define LOWER 0
#define UPPER 300
#define STEP 20

/* Таблица температур по Фаренгейту и Цельсию */
int main(void)
{
    int fahr;

    for (fahr = LOWER; fahr <= UPPER; fahr += STEP)
        printf("%3d %6.1f\n", fahr,
               (5.0 / 9.0) * (fahr - 32));

    return 0;
}
```

Если понадобится изменить диапазон или шаг, достаточно изменить значения в строках `#define`.

## 3. Как работает `#define`

Общий синтаксис:

```c
#define ИМЯ текст_для_подстановки
```

Перед компиляцией препроцессор заменяет имя соответствующим текстом.

Например:

```c
#define STEP 20
```

В выражении:

```c
fahr = fahr + STEP;
```

имя `STEP` заменяется числом `20`.

## 4. Важные правила

- Символические константы обычно записывают **ЗАГЛАВНЫМИ БУКВАМИ**, чтобы отличать их от переменных.
- После `#define` **не ставят точку с запятой**.
- Для символической константы не требуется объявление переменной.
- `#define` выполняет текстовую подстановку, а не создаёт обычную переменную.
- Имя константы должно быть допустимым идентификатором C: начинаться с буквы или `_`, далее могут использоваться буквы, цифры и `_`.

Правильно:

```c
#define MAX_TEMP 300
#define STEP 20
```

Неправильно:

```c
#define STEP 20;
```

В последнем случае точка с запятой тоже подставится в код и может вызвать ошибку.

## Главное запомнить

`#define` позволяет давать числовым значениям осмысленные имена. Благодаря этому код становится понятнее, а изменения диапазонов и шагов требуют меньше правок.
